ARMY3 步槍打靶紙 v1.42 — 中央準星柱頂落點 + 不規律呼吸設定

使用方式
1. 將本 ZIP 解壓縮。
2. 將其中 4 個檔案上傳至 Vmylife/ARMY3 儲存庫根目錄，覆蓋同名檔案：
   shooting-paper-range.html
   shooting-paper.js
   shooting-paper-world.js
   shooting-paper.css
3. 不需要重傳 shooting-paper-scene.json 或 GLB。其他小遊戲不受影響。
4. 測試頁：https://vmylife.github.io/ARMY3/shooting-paper-range.html?v=142

本版修改
- 發射方向、彈道和彈孔改為以「前準星柱最上方」這個相同的畫面點為準，不再以螢幕中心計算。
- 射擊前先取得準星位置，然後才觸發後座力，避免同一發的命中與畫面分離。
- 子彈曳光終點也與同一準星柱頂對齊。
- 遊戲內右側「⚙ 呼吸」按鈕可開啟強度設定（0–100），可隨時調整，並自動記錄設定。
- 0% = 完全不呼吸晃動（保留正常射擊後座力）。
- 100% = 極誇張晃動，方向、加速和停頓都不規則。
- 呼吸由規律正弦波替換為平滑隨機目標 + 阻尼運動，避免每幀隨機跳動，並保留手機效能。
- 修正 3D 步槍水平呼吸方向，使其與 2D 機械瞄具移動一致。
- 不變更靶紙位置、場景地圖、原有 20 發、命中判定尺寸、結算方式。

驗證
- Node.js 語法檢查通過（JS、世界渲染橋接）。
- Chromium 390×844 CSS 像素驗證：0% 無呼吸、100% 大幅不規則晃動、滑桿即時調整。
- 中央柱頂、3D 射線落點、靶紙彈孔的投影座標誤差為零（數學模擬，非真機渲染）。
- 射中會留下彈孔、射偏不記錄、收紙結算及重玩流程正常。
- 尚未在完整 GLB 3D 軍營與 iPhone Safari 真機驗證，部署後請以實際裝置確認。
