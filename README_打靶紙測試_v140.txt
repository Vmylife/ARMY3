ARMY3 國軍射擊鑑測「靶紙版」v1.40

安裝
1. 將 ZIP 解壓縮，裡面 5 個遊戲檔案和 1 個說明檔放進 Vmylife/ARMY3 儲存庫根目錄（與 grenade-user-play-3d.js 同一層）。
2. 保留所有原版 ARMY3 的 GLB、WebGL、地形及音效素材。
3. 瀏覽 https://vmylife.github.io/ARMY3/shooting-paper-range.html?v=140

內容
- 只使用使用者 2026-10-30 上傳之最新 JSON（48 物件）：48 物件原樣保存，並另存 shooting-paper-scene.json。
- 使用唯一友軍士兵 g1001 的座標，作為第一人稱射擊位置，不增加其他 NPC。
- 靶架 main-prop-3（x=12.3,z=22.15）貼上虛擬打靶紙，靶紙的投影跟隨 3D 鏡頭。
- 使用前一版步槍機械瞄具、呼吸擺動、左右上下滑動、2.4x 開鏡；中央柱頂為命中點。
- 彈孔以世界空間射線和平面交點計算，射偏不在靶紙留下彈孔。
- 射滿 20 發、45 秒到期，或按「收靶紙／結算」，靶紙便向鏡頭放大，顯示每一發命中位置、順序與統計。
- 保留原有訓練區、木箱、沙包、爆炸桶、圍欄和地形；本次沒有加入爆炸和移動人群玩法。

修改安全
- 所有檔案都是 shooting-paper-* 新檔，不會覆蓋正式 shooting-range.html、shooting-range.js、其他兩款小遊戲或場景編輯器。
- JSON 由最新使用者提供檔案直接複製；不取代目前正式的 shooting-user-scene.json。
- 重新載入或重玩不修改遊戲既有成就或存檔。

測試／限制
- 已通過 JS 語法檢查、比對原版 GLB 渲染器的 13 處接入點，以及 Chromium 手機尺寸（模擬 3D 橋接）射擊與結算流程測試。
- 已驗證瞄準靶面命中、射偏不記錄、回收靶紙、重新挑戰流程，無頁面 JavaScript 異常。
- 未能在此環境完整載入 GitHub 的 GLB 軍營或在 iPhone Safari 實測。若正式網站首次發生 3D 模型載入錯誤，請附上 Console 截圖以便精準修正。
- 靶紙採用與 3D 靶架對齊的即時 2D 投影貼附；不是修改原本的 target.glb 內部材質，未來可在確認座標後轉為真正的 WebGL 材質平面。
