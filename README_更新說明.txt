ARMY3 v3.21 — 手榴彈「確認敵方位置」運鏡重播

安裝：將本 ZIP 中的檔案依相同路徑覆蓋至 GitHub Vmylife/ARMY3 根目錄。
不需要上傳 README；其餘三個 JS 才是更新檔。

功能：
- 投擲場瞄準期間，在螢幕左方新增「確認敵方位置」按鈕。
- 重播與原始開場相同的 7 秒鏡頭：紅軍位置 → 俯視營區 → 投擲者後方。
- 播放期間隔離點擊以避免誤鎖計量條、誤丟手榴彈。
- 播放期間按鈕變為「跳過運鏡」，可立即恢復。
- 完成後回到原本的左右／遠近瞄準階段；不重置三投、敵軍或破壞結果。
- 投擲、爆炸和結算時按鈕自動隱藏。
- 按鈕適配手機安全區，不允許長按選取文字。

更新內容：
- src/systems/grenadeEnemyReview.js：新功能獨立模組。
- src/systems/grenadeArenaSfx.js：附加鏡頭按鈕模組，不修改舊音效程式。
- src/systems/grenadeWorkshopSfx.js：更新依賴版本號確保新模組可被載入。

測試：JavaScript 語法，模擬手機（390×844）按鈕位置，鏡頭進度，跳過重播，阻止誤觸，瞄準階段保持，投擲階段隱藏。尚未在實際 iPhone 及完整 3D 場景上驗證。
