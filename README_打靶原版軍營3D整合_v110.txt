ARMY3 第一人稱打靶 v1.10 — 原版軍營 3D 模型整合 / 觸控方向修正

覆蓋到 Vmylife/ARMY3 的 main 分支專案根目錄（保留路徑）：
  shooting-range.html
  shooting-range.js
  shooting-range-world.js（新增）

本版沿用 v1.00 第一人稱槍枝與呼吸晃動，主要改動：
1. 手指往上滑＝槍口朝上，往下滑＝槍口朝下（原版方向修正）。
2. 3D 背景不再獨立手繪；會讀取原本 grenade-user-play-3d.js、grenade-user-scene.json，顯示 ARMY3 原軍營地面、建築、道具。
3. 紅軍與友軍在 3D 模式沿用 cadet-green.glb、高品質角色骨架、既有走路／跑步／拉單槓／掃地等動畫，並按本打靶的 NPC 模擬位置更新。
4. 紅色桶子使用現有 assets/props/barrel.glb 網格與貼圖，將模型調成紅色；原搬運與落桶邏輯保留。
5. 紅桶爆炸觸發原本手榴彈 3D 場景的爆炸、衝擊與碎片演出，原打靶遊戲計分與傷亡仍由射擊模擬負責。
6. 保留既有第一人稱槍械 UI、按住射擊、呼吸、20 發彈匣、45 秒結算、音效和返回軍營。
7. 3D 場景模型未載入前及 WebGL 無法使用時，顯示原本簡化場景，避免手機黑畫面。

重要：此更新包不包含重複的 GLB、音檔、場景 JSON 或 grenade-user-play-3d.js，必須先有完整 ARMY3 儲存庫才能運作。
此版利用動態模組介接來重用現有 3D 渲染器，未修改原本的手榴彈／棉被程式。

測試情況：
- 已通過 JS 語法檢查、3D 接口模擬載入、第一人稱觸控方向（上滑仰角上升、下滑仰角下降）、開槍與爆炸邏輯的 Chromium 測試。
- 測試環境沒有原本遊戲的大型 GLB 模型資料；最終 3D 圖像、效能、iPhone Safari 相容性尚未實機確認。
- 如 3D 模組版本異動、無法成功載入，會自動保留 v1.00 簡化畫面，並顯示提醒。

此更新只對你已安裝的 ChatGPT 打靶遊戲生效，不會更動 Codex 的 codex-shooting-experiment 分支。
