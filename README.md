# ARMY2 — 完整部署版（整理版）

此資料夾是以 2026-10-29 GitHub `Vmylife/ARMY2` 的 `main` 為基準重建，套用當時所有正式程式與更新後整理的版本。

## 功能與入口

| 頁面 | 功能 |
| --- | --- |
| `index.html` | 軍營主遊戲：原版地圖、NPC、地圖/小地圖、角色移動與動畫、訓練點 |
| `grenade-workshop-test.html` | 手榴彈製作工坊：裝填、壓實 QTE、轉輪塑形；背景載入投擲場 |
| `grenade-user-play.html` | 手榴彈 3D 投擲：製作威力、連投三次、累計破壞、提前結算、獎章與返回軍營 |
| `editor.html` | 正式軍營編輯器 |
| `grenade-scene-editor.html` | 手榴彈場景編輯器（主遊戲地圖同步、可破壞物件、低畫質模型） |
| `animation-lab.html` | 動畫校正/測試工具（現有 NPC 動作會引用其輔助模組） |

## 上傳到 GitHub Pages 時請注意

這個 ZIP **是完整網站**，不是增量更新。

直接將新檔案覆蓋到既有儲存庫，**不會自動刪除 GitHub 裡已不再需要的舊檔案**。若要真正同步成整理版，請參考附帶的 `CLEANUP_REMOVED.txt` 刪除清單，或先在新分支乾淨地上傳完整資料夾並檢查功能後取代主分支。

網頁紀錄、成就與編輯器本機草稿儲存在各個裝置的瀏覽器（localStorage/sessionStorage），不包含在 ZIP 中，請勿清除現有瀏覽器資料。

此版本經過檔案完整性、引用檢查、JS 語法和 GLB 結構檢查；尚未進行 iPhone WebGL2 的完整實機驗證。
