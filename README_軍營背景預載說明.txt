《國軍當兵模擬器》v1.90｜軍營背景預載＋小遊戲快速進場

安裝方式：
1. 解壓縮 ZIP。
2. 保留資料夾結構，覆蓋 GitHub Vmylife/ARMY3 的根目錄。
3. 重新整理遊戲頁面，建議首次更新使用完整重新整理以避開舊 JS 快取。
4. 本包只包含本次修改的檔案，不需要重新裝前版音樂或音效。

改動項目：
• 軍營載入完成後，用空閒時間依序預先下載兩個小遊戲的頁面、音效、背景音樂、JavaScript、場景 JSON、部分主要 GLB 模型，讓重複請求優先命中瀏覽器快取。
• 接近棉被／手榴彈入口約 11m 時，最多只預熱一個 iframe 真正建立小遊戲場景；走遠會釋放預熱的 iframe，避免同時運作多個 3D 場景。
• 選擇進場時直接顯示原先已載入的 iframe，不再因整頁跳轉重做同一批模型；若玩家太快到達，仍使用該 iframe 本身的載入流程，不會鎖住入口。
• 手榴彈背景預熱透過遊戲內原有的開始按鈕流程，建立巢狀 3D 投擲場後恢復開始畫面；真正操作仍需玩家再按一次開始。
• 手榴彈音效與背景音樂提早初始化；iOS 首次觸控才解鎖播放（符合瀏覽器限制）。
• 開啟小遊戲時暫停底下軍營的 WebGL 迴圈和音樂，返回時恢復原本遊戲中的角色位置，不重新載入軍營。
• 保留原本棉被 38 項成就、音效與背景音樂、手榴彈玩法和評分。
• 低速省流模式不主動下載大量資源；接近入口時仍可依需求預熱。

注意：
• 這是「空閒下載＋靠近入口預建」的分段策略，不是開場一次同時解析兩座 3D 軍營；能降低卡頓與記憶體壓力。
• 進軍營後立即衝去入口、網路很慢、手機記憶體回收時，仍可能看見部分載入畫面；無法保證每次零秒等待。
• 音訊在 iPhone Safari 必須經過真實觸控才可以播放，預載只能避免等待音檔，不代表可以在未觸控時自動發聲。
• 本次通過 Node JavaScript 語法與關鍵版本／流程靜態檢查；未完成 iPhone 實機測試，建議更新後依序試：軍營走動 10 秒→棉被入口→返回→手榴彈入口→檢查第一次按開始有音樂／音效。
