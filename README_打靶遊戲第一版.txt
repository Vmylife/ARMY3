ARMY3 / 第一人稱打靶試玩 v1.00

安裝：
將 ZIP 的檔案依照原本資料夾結構覆蓋到 Vmylife/ARMY3 的 main 分支。
這是差分更新，不需要把原本遊戲刪掉。請勿將 ZIP 本身上傳後當作頁面執行。

試玩方式：
1. 原本首頁點「🎯 試玩打靶小遊戲（第一版）」，不用先載入整個軍營。
2. 進入軍營後也會有「🎯 打靶試玩」按鈕。
3. 上傳後亦可使用 https://vmylife.github.io/ARMY3/shooting-range.html 直接開啟。
4. 滑動畫面瞄準，右下按住射擊，左下換彈，45 秒後結算。
5. 結算後可重試或回軍營；從軍營以彈出試玩視窗啟動時，返回保留原軍營頁面。

本版本已完成：
- 45 秒第一人稱打靶、滑動瞄準、呼吸晃動與槍口上跳
- 20 發彈匣／換彈／NPC 命中與傷亡
- 紅軍友軍跑動／掃地／拔草／拉單槓行為
- 開場 3 個紅色桶；紅軍與友軍可從場外搬桶入場並放下
- 紅桶被射擊才爆炸、距離傷害、擊飛、連鎖爆炸
- 沿用 B 版槍聲及手榴彈爆炸素材、簡易結算與趣味勳章
